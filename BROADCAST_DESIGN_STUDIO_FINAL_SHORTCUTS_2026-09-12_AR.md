# WAB-TKD Broadcast Design Studio — Final Shortcuts & Editor Pass

## Added
- Photoshop-style keyboard command layer for the Design Studio.
- Undo/Redo, Save, Duplicate, Group/Ungroup, layer ordering, Delete.
- Space playback, Home/End timeline navigation, Arrow stepping, K keyframe, F freeze.
- F2 layer rename.
- V/T/R/I/E quick tools for Move/Text/Frame/Image/Effect.
- Escape deselects and closes shortcut help.
- Grid, Guides and Snap toggles exposed in the editor toolbar.
- Multi-layer grouping now groups all selected layers and calculates the group bounds from the selected content.
- Shortcut help modal.

## Existing final-engine capabilities retained
- Per-animation design isolation.
- Time-local keyframes and easing.
- Dynamic data bindings.
- Frame styles, gradients, effects, blend modes, clipping.
- Presets.
- Public Display design synchronization.

## Verification note
The supplied archive does not include a complete dependency installation, so a full production build cannot be claimed as verified in this environment.
